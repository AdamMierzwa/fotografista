### Why MPL 1.1 and not LGPL 2.1

Graphics32 is dual-licensed. We distribute it under **MPL 1.1**. The LGPL
variant (as published by Graphics32, the Free Pascal-modified LGPL 2.1) would
add relinking obligations that a closed-source Delphi application cannot
practically satisfy.

MPL 1.1 permits this: it treats the application as a "Larger Work" that may be
distributed under any terms, including proprietary ones, provided the
MPL-covered files themselves stay available and unmodified.

The source of Graphics32 is included in this repository at
`Lib/Graphics32/Source/`, which satisfies the MPL source-availability
requirement.

### Version pinning

The archive was extracted without version-control metadata, so no upstream
commit hash is known. `Lib/Graphics32/Source/` (246 files) is therefore
pinned by a **content manifest** rather than by a revision. To reproduce it,
from the repository root:

```powershell
powershell -ExecutionPolicy Bypass -File tools\mankist_graphics32.ps1
```

The script normalises line endings to LF before hashing and sorts paths
ordinally, so the result does not depend on the checkout style or on the
system locale. SHA-256 of the resulting manifest:

```
1dc5e2b21ce7fb769f5caaaf92e4a43406a9228cd828408846bd0f8a8610dcc4
```

## VCL styles

| | |
|---|---|
| Component | Embarcadero VCL style files |
| Location | `Styles/*.vsf` (35 files) |
| Rights holder | Embarcadero Technologies, Inc. |
| Source | RAD Studio 37.0, `Redist\styles\vcl` |
| Status | Redistributable per the RAD Studio deployment documentation |

The `.vsf` files are compiled style resources and embed no copyright header
of their own. Redistribution is established by the product documentation, not
by a notice inside the files.

Embarcadero's deployment documentation (`radstudio_deploy_en.htm`, section 3,
"VCL and FireMonkey Styles") states verbatim:

> The product includes a library of redistributable VCL and FireMonkey style
> files installed in the `\Users\Public\Documents\Studio\37.0\Styles`
> directory, or equivalent OS specific location. These files may also be
> modified and freely redistributed as part of your larger work under a new
> name.

These styles are loaded at runtime by `fMain.pas` (`LoadExternalStyles`), which
scans the `Styles\` directory for `*.vsf` files. Without them the application
still starts, but no VCL themes are available.

Of the 35 files, 28 are byte-identical to the copies shipped in RAD Studio
37.0. The remaining 7 (`Windows10.vsf`, `Windows10Blue.vsf`, `Windows10Dark.vsf`,
`Windows10Green.vsf`, `Windows10Purple.vsf`, `Windows10SlateGray.vsf`,
`Glow.vsf`) differ from them by 1-10 bytes; their exact origin was not
determined. The permission quoted above covers modification and redistribution
regardless of which release a given file came from.

Only `.vsf` files are included. The FireMonkey `.Style` files and `.png`
assets from the same library are not used by this VCL application and are not
included.
